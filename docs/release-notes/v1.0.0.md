Первый публичный релиз.

**Что внутри**
- Каталог из 27 скрытых настроек Apple Music (проверено на версии 6.5.3).
- **Root:** переключатели прямо в приложении — авто-снижение качества, выбор дорожки, измеритель скорости, качество Wi-Fi/сота, Lossless, Dolby Atmos, нормализация громкости и отладочные флаги. Большая кнопка «Выключить» для адаптивного качества.
- **Shizuku:** открывает встроенное скрытое меню отладки Apple Music (экспериментально).
- Material You: цвета подстраиваются под обои.

**Установка**
Скачай `AMTweaks-1.0.0.apk` ниже и установи. Если ставил тестовую сборку `build-1` — сначала удали её: у релиза новый ключ подписи.
